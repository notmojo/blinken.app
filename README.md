# blinken.app

Sito di [Blinken](https://blinken.app), l'app iOS che aggiorna l'homelab: pagina iniziale, privacy e supporto,
in italiano e inglese sullo stesso indirizzo (`#it` / `#en`, altrimenti la lingua del browser).

HTML statico pubblicato con GitHub Pages dal ramo `main`. L'app linka `https://blinken.app/privacy`.

Anteprima in locale:

```bash
python3 -m http.server 8790 --bind 127.0.0.1
```
